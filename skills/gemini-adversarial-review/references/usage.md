# Usage and boundaries

Requires Linux, Python 3, Git, `bwrap`, and an authenticated `agy` CLI. This installation was checked with `agy` 1.2.12. The helper uses `--print`, `--model`, `--output-format json`, `--print-timeout`, and `--disable-slash-commands`. `agy models` lists available model IDs. No documented quota status command appeared in this version's help, so the helper detects quota/auth failures from the review result. The CLI has an `agent` listing command, but no custom agent or permission-rule configuration is needed: the rubric and all selected source material are passed in the prompt, and Linux mount isolation enforces the repository boundary. The helper does not request command execution; headless Antigravity soft-denies commands that require approval.

The helper picks the highest-version `gemini-*-pro-high` listed by `agy models`. If none exists, it falls back to the highest-version `gemini-*-pro-low`; if neither exists, it fails closed. `--model ID` selects any listed model. It does not pass `--effort`: the available model slug already selects its effort, and forcing high effort makes Pro Low invalid. At installation, `gemini-3.1-pro-high` was the best listed Pro model. Antigravity's JSON result does not echo the model ID, so output metadata records the requested model, not an independently attested model.

Preview with no `--run`; the JSON manifest lists changed paths, explicitly included untracked paths, context paths, total bytes, and a SHA-256 digest of the patch and copied file bytes. Inspect the listed material. Pass that digest as `--run --expect-sha256 HASH`; if the source changes, the helper refuses to send it. `--run` emits the manifest to stderr immediately before sending. The review output is JSON on stdout and includes raw text, conversation ID, usage, and selection metadata. Raw reports are not saved by the helper.

For "this PR," the skill uses `gh pr view` to identify the PR's current base and head commit IDs, verifies the local checkout matches the head, and passes the base commit ID to `--branch`. This makes the review cover committed PR changes even when the working tree is clean. The base commit must exist locally; a missing base or mismatched head must be resolved before sending. Dirty local changes remain outside the PR selection.

The source repository is not mounted into the `bwrap` namespace. Only a temporary copy of selected file contents and `diff.patch` is mounted at `/review` read-only. A temporary writable home holds a copy of the existing Antigravity OAuth token and the cached project ID, so the CLI can authenticate and write its own session state. System binaries, system config, devices, and the resolver are mounted as needed. The sandbox inherits no host environment variables. The temporary home and snapshot are deleted after the run. The Antigravity process can necessarily access its copied token; the helper does not expose the original home directory or Git checkout. It does not pass `--dangerously-skip-permissions`.

Only regular UTF-8 text files are supported. Symlinks, submodules, binary changes, and selections above 400 KB fail closed. `--deep` changes the review instructions; add explicit `--context-path FILE` entries to provide surrounding code beyond changed files. Context files are taken from the current worktree, even for a revision comparison, and are shown in the preview. The helper does not include a full repository tree or secrets outside the listed paths. `--path` accepts one file or directory. Empty diffs are errors. The CLI prompt includes code in a process argument while `agy` runs; other local processes with permission to inspect this user's process arguments could see it.
